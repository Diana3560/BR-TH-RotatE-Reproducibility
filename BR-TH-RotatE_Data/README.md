# CRH-L4MKG Data Audit and Reproducibility Package

本数据包用于复核 CRH-L4MKG 链接预测实验所采用的图结构、固定数据划分与评价输入。原始非匿名数据集不公开，因此本包采用稳定匿名实体编号，仅保留复核实验所需的结构信息。

## 可复核内容

- 13 类实体及其数量；
- 17 类关系及完整图谱逐关系数量；
- R14 固定 Train/Validation/Test 匿名结构化边列表；
- R14 各关系在 Train/Validation/Test 中的数量；
- 13,693 个主评价候选实体的匿名编号与实体类型；
- Train-only 关系-类型 Schema；
- 固定划分中的重复项、划分重叠、关系覆盖和候选实体数量；
- 公开文件 SHA-256 校验值；
- 280 条固定分层样本的结构一致性审计。

## 关键规模

- 节点记录：13,696
- 至少参与一条三元组的实体 / 主评价候选实体：13,693
- Full17 三元组：24,768
- R14 三元组：17,430
- R14 Train / Validation / Test：15,413 / 1,009 / 1,008
- R14 涉及实体：11,653

## 数据构建与人工复核

初始知识抽取、实体规范化与结构化整理由 1 名研究人员完成，形成初始结构化结果后由 2 名专家进行人工复核。复核内容包括实体类别、关系语义与方向、同义表达归一化及工艺步骤从属关系等。

## 公开边界

公开文件不包含真实实体名称、原始规程文本和匿名 ID 与真实名称之间的映射。匿名化仅替换实体标识，不改变实体类型、关系类型、图拓扑或固定划分成员关系。

## 自动验证

运行：

```bash
python scripts/verify_package.py
```

脚本检查公开文件哈希以及固定划分的核心结构约束。
