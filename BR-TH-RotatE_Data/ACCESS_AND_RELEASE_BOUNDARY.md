# Data Access and Release Boundary

原始非匿名 CRH-L4MKG 数据集不公开。为支持论文实验复核，本数据包提供匿名化后的结构数据和固定划分。

## 公开内容

- 稳定匿名实体编号及实体类型；
- 关系类型与关系 Schema；
- R14 固定 Train/Validation/Test 匿名边列表；
- 实体与关系数量统计；
- 逐关系固定划分统计；
- Train-only 类型约束 Schema；
- SHA-256 校验值与自动验证脚本。

## 不包含内容

- 真实实体名称；
- 原始规程全文；
- 匿名 ID 与真实实体名称之间的映射；
- 非公开的原始数据整理文件。

匿名化过程仅替换实体标识，不改变实体类型、关系类型、图拓扑或固定划分成员关系。因此，该公开版本用于复核论文主要链接预测实验的数据规模、划分结构与模型评价输入。
