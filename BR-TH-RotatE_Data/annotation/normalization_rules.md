# 实体规范化、同义表达与重复项处理说明

以下内容仅记录论文及冻结结构化数据能够确认的处理方式。

1. **统一实体标识**：结构化实体使用唯一实体 ID 作为关系端点，关系三元组通过实体 ID 连接。
2. **实体类型固定**：实体按照既定 13 类 Schema 记录类型，评价阶段不依据表面字符串重新推断实体类型。
3. **名称与同义表达规范化**：数据构建过程中对名称、标识、类别和同义表达进行统一整理，并由人工复核检查同名内容合并。
4. **关系端点解析**：进入最终图谱的关系记录应能够解析到已登记的实体节点。
5. **重复三元组处理**：最终公开的 Full17 与 R14 固定划分以 `(head, relation, tail)` 作为结构化边表示；公开固定划分中不存在重复三元组。
6. **未参与关系的节点**：节点表记录 13,696 个实体，其中 13,693 个至少出现在一条三元组中并构成主评价候选集合；其余 3 个节点保留在节点记录中，但不进入该候选集合。

本说明不额外补充冻结项目记录中未明确保存的字符串级预处理细节。
