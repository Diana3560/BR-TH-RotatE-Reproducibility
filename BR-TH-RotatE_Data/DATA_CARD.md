#  CRH-L4MKG Data Card

## 1. 数据范围

CRH-L4MKG 包含 13 类实体和 17 类关系。完整图谱包含 **24,768 条三元组**，其中 **13,693 个实体至少参与一条三元组**。用于链接预测的 R14 推理层包含 **17,430 条三元组**，涉及 **11,653 个实体**。

## 2. 固定 R14 划分

- Train：**15,413** 条
- Validation：**1,009** 条
- Test：**1,008** 条
- 14 类 R14 关系均出现在三个子集中；
- R14 涉及的 11,653 个实体均在 Train 中出现；
- Train/Validation/Test 两两无三元组重叠；
- 三个划分文件均无重复三元组。

逐关系数量见 `statistics/relation_split_counts.csv`。

## 3. 候选实体空间

主评价在完整图谱中至少参与一条关系事实的 **13,693 个实体**上进行排序，而不是仅使用 11,653 个 R14 实体。匿名候选实体 ID 与实体类型见 `anonymized_data/candidate_entities.tsv`。

## 4. 类型约束敏感性实验

关系允许的头、尾实体类型由 **Train-only** 数据生成，Validation/Test 不参与该 Schema 的构造。冻结后的 Schema 见 `schema/type_constrained_schema_train_only.json`。

## 5. 数据构建与人工复核

初始知识抽取、实体规范化与结构化整理由 **1 名研究人员**完成，随后由 **2 名专家**对结构化结果进行人工复核。复核重点包括实体类别、关系语义与方向、同义表达归一化及工艺步骤从属关系。

## 6. 可复核的数据质量检查

本包提供并可重复检查：

- Full17 的冻结统计结果及源文件 SHA-256，并支持对 R14 公开结构和固定划分进行直接复核；
- Train / Validation / Test 文件内重复项；
- 三个固定划分之间的三元组重叠；
- 14 类关系在固定划分中的覆盖情况；
- 主评价候选实体数量；
- Train-only 关系-类型 Schema；
- 公开文件 SHA-256 校验值。

此外，`integrity/retrospective_structural_audit_280.csv` 提供 280 条分层样本的结构一致性审计结果。

## 7. 匿名化公开范围

原始非匿名数据集不公开。本包不包含真实实体名称、原始规程文本或匿名 ID 与真实名称之间的映射。匿名化处理只替换实体标识，保持关系类型、图拓扑和固定数据划分不变，以支持第三方复核主要链接预测实验的数据结构与输入条件。
