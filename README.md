# BR-TH-RotatE Reproducibility Package

This repository contains the code and anonymized data supporting the experiments reported for BR-TH-RotatE.

## Repository Structure

- `BR-TH-RotatE/` — source code, experiment configurations, evaluation scripts, tests, and manuscript result files.
- `BR-TH-RotatE_Data/` — anonymized CRH-L4MKG data, schema definitions, annotation documentation, statistics, and integrity verification files.

## Code

The implementation and experiment instructions are available in:

`BR-TH-RotatE/`

See `BR-TH-RotatE/README.md` for detailed setup and reproduction instructions.

## Data

The anonymized dataset package is available in:

`BR-TH-RotatE_Data/`

See `BR-TH-RotatE_Data/README.md` and `BR-TH-RotatE_Data/DATA_CARD.md` for dataset structure, release boundaries, and usage notes.

## Repository Status

This repository is currently maintained as a private reproducibility package. Repository visibility may be changed in accordance with manuscript review and data-release requirements.
